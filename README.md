## 구현 기능 목록

## 사전 세팅 기능
* [x] 12월 크루들의 출결 정보를 읽어온다. (src/main/resources/attendances.csv)
  * [x] 출결 정보를 객체로 파싱한다. -> 객체 : 크루명, 출석일, 출석시간, 출석 상태(출석, 지각, 결석)
* [x] 12월 출결 정보를 저장소에 세팅한다.

## 매뉴 선택 기능
*[x] DateTimes.now()를 통해 오늘 날짜를 받는다.
  * [x] LocalDate.of()를 통해 오늘 날짜를 2024.12.13.(금)로 고정한다.
* Commend를 입력받는다.(1,2,3,4,Q)
  * [x] 입력값 검증 : **재시작 아님, 프로그램 종료 주의**
~~~
오늘은 12월 13일 금요일입니다. 기능을 선택해 주세요.
1. 출석 확인
2. 출석 수정
3. 크루별 출석 기록 확인
4. 제적 위험자 확인
Q. 종료
1
~~~
---
## 출석 확인
* [x] 검증 : 오늘이 출석 가능한 날인지 (주말, 공휴일)
### 크루 이름 입력 기능 // 이든
  * [x] 검증 : 입력 형태
  * [x] 검증 : 저장소에 있는 크루원인지
  * [x] 검증 : 오늘 이미 출석한 크루인지
### 출석 시간 입력 기능 // 09:30
  * [x] 검증 : 입력 형태
  * [x] 검증 : 출석 가능 시간(캠퍼스 운영시간) // 08:00 ~ 23:00
### 요일별 출석 시간에 따른 상태(출석, 지각, 결석) 계산 기능
  * [x] 출석 상태 계산 
    * 월요일(출석= ~ 13:05, 지각= 13:06 ~ 13:30, 결석= 13:31 ~)
    * 화~금(출석= ~ 10:05, 지각= 10:06 ~ 10:30, 결석= 10:31 ~)
* 참고 : 등교하지 않은 날은 자동으로 결석 처리.
### 출석 결과를 출석표(저장소)에 저장
  * [x] 크루명, 출석일, 출석시간, 출석 상태(출석, 지각, 결석)을 객체로 만들기
  * [x] 위 객체를 저장소에 저장

~~~
닉네임을 입력해 주세요.
이든
등교 시간을 입력해 주세요.
09:59

12월 13일 금요일 09:59 (출석)
~~~

## 출석 수정
### 크루 이름 입력 기능 // 이든
  * [x] 검증 : 입력 형태 // 문자인지?
  * [x] 검증 : 저장소에 있는 크루원인지
### 수정 날짜 입력 기능 // 3
* 참고 : 출석을 안한 결석이 자동으로 사전에 저장소에 세팅되어야 한다.
  * [x] 검증 : 입력 형태 // 1
  * [x] 검증 : 12월 안에 있는 날짜인지(1일 ~ 31일)
  * [x] 검증 : 수정 할 수 있는 날인지(주말, 공휴일)
### 변경 시간 입력 기능
  * [x] 검증 : 입력 형태 // 09:30, 12:30
  * [x] 검증 : 캠퍼스 운영 시간대(08:00 ~ 23:00)
### 날짜, 변경 시간을 통해 출석 상태(출석, 지각, 결석) 계산
  * [x] 출석 상태 계산
     * 월요일(출석= ~ 13:05, 지각= 13:06 ~ 13:30, 결석= 13:31 ~)
     * 화~금(출석= ~ 10:05, 지각= 10:06 ~ 13:30, 결석= 10:31 ~)
### 이름, 날짜를 통해 출석표(저장소)에서 조회
  * [x] 조희한 출석 객체 삭제
  * [x] 최종 적으로 수정한 출석 객체 저장소에 저장

### 최종 수정 결과 출력
* ex) 12월 03일 화요일 10:07 (지각) -> 09:58 (출석) 수정 완료!
~~~
출석을 수정하려는 크루의 닉네임을 입력해 주세요.
빙티
수정하려는 날짜(일)를 입력해 주세요.
3
언제로 변경하겠습니까?
09:58

12월 03일 화요일 10:07 (지각) -> 09:58 (출석) 수정 완료!
~~~

## 크루별 출석 기록 조회 확인
### 크루 이름 입력 기능 // 이든
  * [x] 검증 : 입력 형태 // 문자인지?
  * [x] 검증 : 저장소에 있는 크루원인지
### 저장소에서 크루 이름으로 출석정보들 조회 기능
  * 전날 까지 출석 정보 조회(1일부터 ~ 어제까지)
  * [x] 해당 크루의 출석 정보 날짜 순으로 정렬기능
  * [x] 출석, 지각, 결석 횟수 계산
  * [x] 대상자 상태 계산(정상, 경고, 면담, 제적)

## 제적 위험자 확인
* [ ] 최종 제적 위험자 출력
  * [ ] 저장소에서 모든 크루원들 대상으로 상태(정상, 경고, 면담, 제적) 계산
  * [ ] 객체 생성하여 가져오기(이름, 결석, 지각, 상태)
  * [ ] 정렬
    * [ ] 상태 순서로 정렬(제적, 면담, 경고 순서)
    * [ ] 각 상태별 순서 정렬(지각3회를 결석1회로 간주하여 결석 횟수로 내림차순 정렬)
      * [ ] 결석 횟수가 같다면 이름 순서로 정(ㄱ,ㄴ,ㄷ...)
~~~
제적 위험자 조회 결과

- 빙티: 결석 3회, 지각 2회 (면담)
- 이든: 결석 2회, 지각 4회 (면담)
- 쿠키: 결석 2회, 지각 2회 (경고)
- 빙봉: 결석 1회, 지각 5회 (경고)
~~~
